## 1. 快速开始

线上 0.4.1 的入口使用青色 R 与蓝紫色 S 组成的标志。通过 [项目官网](https://rescene.xyz/#delivery) 可核对各端的正式版本和验收进度。GPU Worker 离线时任务继续排队，不影响登录、上传和查看历史结果。

以下菜单名称对应当前开发版；线上与安装包的功能以各自版本为准。

1. 用邮箱和密码登录；首次使用可选「注册」，密码至少 12 位。
2. 在「项目列表」点击「新建项目」，或按名称搜索并打开已有项目。
3. 在「素材」导入一组围绕目标拍摄的图片，或导入一段连续视频。勾选可用素材后点击「配置重建」。
4. 选择路线并点击「开始重建」。计算节点离线时，任务仍可排队。提交成功后直接进入该任务的「任务详情」。
5. 任务成功后选「查看结果」。可打开三维场景；下载、校验和分享取决于平台和权限。微信小程序可复制链接至外部浏览器查看私有场景。

登录后在「设置 → 账户 → 修改密码」输入当前密码完成改密；旧会话失效，当前设备使用新令牌。忘记密码时联系平台管理员重置。项目所有者或平台管理员可管理项目成员。

## 2. 账号、项目与权限

| 角色 | 查看素材/任务/结果 | 上传、建任务、取消任务、分享管理 | 项目设置、成员、删除项目 |
|---|---:|---:|---:|
| `owner` | 是 | 是 | 是 |
| `admin`（平台管理员） | 是 | 是 | 是 |
| `member` | 是 | 是 | 否 |
| `viewer` | 是 | 否 | 否 |

- 平台管理员是账号级权限，不是项目成员角色，可管理所有项目；`owner` 是项目所有者，`member` 和 `viewer` 是项目成员角色。
- 邮箱与退出登录入口位于「设置 → 账户」。计算节点状态只在配置和任务等相关页面提示，离线时任务仍保持排队。
- Web/桌面窄窗把全局导航折叠为菜单：项目列表、通知和设置。按 `Esc` 关闭菜单；打开新页面后，键盘焦点移到该页标题。
- 「通知」单独显示公告与任务完成、失败消息，任务通知可打开对应任务。
- 项目所有者和平台管理员可重命名项目、管理成员和删除项目。在「成员」区填写受邀邮箱、选择角色，再点击「签发邀请」。复制页面短时显示的领取码，私下交给受邀者。领取码 7 天内有效，仅可使用一次。
- 受邀者使用受邀邮箱登录后，在项目列表输入领取码并点击「领取邀请」。没有账号时先注册。重新签发会让上一枚领取码失效。Web 和桌面可查看、撤销待处理邀请，并在成员列表调整已有成员的角色。
- 已有成员继续使用当前权限。旧版创建的待处理邀请，以及旧客户端签发但未显示领取码的邀请，需由管理者在新版客户端重新签发。
- 删除项目会隐藏项目及其任务，并使该项目的公开分享无法访问；如需显式撤销分享，请在删除项目前操作。
- 页面断网时顶部会提示；恢复网络后可继续上传、查询任务和查看结果。

### 管理控制台（仅平台管理员）

平台管理员在左侧栏有“管理控制台”入口，Web、桌面端、Android 与小程序提供同一套三个页签：

| 页签 | 能做什么 |
|---|---|
| 用户 | 按邮箱搜索、按启用状态筛选、分页浏览；停用/启用账号、重置初始密码、查看账号加入的项目与角色、创建账号 |
| 公告 | 发布标题 + 正文 + 级别（信息/警告/重要）；撤回公告 |
| 操作日志 | 按操作者和动作筛选并分页；Web/桌面还提供项目 ID、起止时间筛选与 CSV 导出 |

- 停用账号或重置密码会立刻让该账号的所有会话失效，对方下次请求返回 401。
- 初始密码至少 12 位；重置后需把新密码线下告知对方。
- 公告发布时会给每个“启用”状态的账号各写一条通知；撤回公告会同时删除这些通知。
- 全局审计 API 支持动作前缀（如 `user.`）；Web/桌面提供已有动作选择和 CSV 导出，CSV 带 UTF-8 BOM，最多 10000 行。Web/桌面项目设置还显示项目审计记录。
- 普通账号看不到入口，直接调用对应接口返回 403。

## 3. 拍摄与素材准备

- 围绕目标平稳移动，保持相邻照片有较大重叠；避免只在一个方向拍摄。
- 避免运动中的行人、车辆和反光/透明表面占据主体；固定曝光和白平衡可减少颜色跳变。
- 图片支持 JPG/PNG 等常见格式；视频支持 MP4/MOV/MKV/AVI/WEBM/M4V。
- 一个任务选择同一组图片，或且仅一个视频，不能混选。
- 建议 20–80 张图片用于常规场景；QUALITY 可处理更多帧，但耗时和显存更高。
- 上传上限：单文件 5 GiB，任务合计 8 GiB。浏览器分片上传写 OSS，刷新页面后可从本地断点继续。

## 4. 上传、排队与取消

1. 打开项目，在“素材”区域选择图片或视频。图片可多选，视频只选一个。
2. 每个文件显示上传进度和状态：
   - `UPLOADING`：正在上传；
   - `READY`：服务端已通过 HEAD 与 SHA-256 校验；
   - `FAILED`：上传或校验失败，可点击“重试上传”。
3. 只有 `READY` 素材可参与任务。选择一组同场景图片或一个视频。图片建议选 20–80 张，过少或可用视角不足可能导致重建失败。
4. 选择路线后点击“开始重建”。任务进入 `QUEUED`，Worker 领取后变为 `RUNNING`。
5. 任务运行中可点击“取消任务”。取消会请求 Worker 停止；状态以服务端返回为准。
6. 对显示「重试任务」的失败或取消记录，有写权限的成员可使用同一组素材重新排队。若提示素材无效，请更换素材后创建新任务，原失败记录会保留。

断点上传的本地记录保存在浏览器/客户端本地存储。清除站点数据或换设备后，需要重新上传。

### 外观与素材选择

登录前打开「外观」，或登录后进入「设置 → 外观」。主题可跟随系统、使用浅色或深色；配色可选青瓷素影、群青远山、墨染松烟、胭脂海棠、朱砂落印、赭石秋峦、靛青夜泊，或自定主色并输入六位十六进制颜色，每个方案都用圆角小方块预览主色调。第一次使用的设备默认跟随系统并使用群青远山。自定义主色在点击「应用主色」后生效。字号可选标准、较大、特大，面板可跟随设备或使用实色。Viewer 画布始终为深色。

外观按设备保存，不随账户同步，退出登录后也会保留。若设备存储失败，本次运行仍使用所选外观，但下次打开可能恢复到上次保存的值。「恢复默认外观」不清除业务数据。切换外观不会清空当前表单、勾选或上传队列。Web 刷新会恢复当前项目、素材或任务页及跨页已选素材；退出登录会清除这些本机会话选择。

项目列表每页最多 8 项。素材和任务按服务端游标翻页，不显示估计的总页数；失败时保留原页，可重试。「全选本页图片」只加入本页就绪图片，翻页保留已选素材。缩略图由服务端鉴权后签发，五分钟有效，预览失败可重试。已被任务引用的素材受删除保护。

四端项目均用「素材 / 任务 / 结果」切换。素材底栏只显示已选数量和「配置重建」。配置页显示数量、体积和路线；返回素材仍保留本次选择。「结果」只显示当前任务页中成功并已生成成果的任务。

任务详情会区分计算节点在线等待领取、节点离线和状态暂不可确认。节点离线时可以继续上传、管理项目和查看历史结果，待节点上线后自动领取。

## 5. 路线选择

| 路线 | 适合场景 | 特点 |
|---|---|---|
| FAST | 构图检查、快速预览 | VGGT 前馈几何，7k 步训练，最快 |
| BALANCED | 默认交付、画质与耗时平衡 | VGGT + Bundle Adjustment，20k 步 |
| QUALITY | 高精度几何与最终展示 | COLMAP SfM/BA/MVS，20k 步；耗时最长，注册率可能低于 100% |

路线是质量/资源取舍，不是“同一结果的不同速度”。需要可复现的比较请使用同一素材、同一路线和同一验证集。

## 6. 任务详情与 Viewer

任务详情显示该任务的状态、进度和阶段，可单独打开「运行日志」。任务成功后，用「查看结果」打开该任务的成果详情；也可在项目的「结果」列表点选成果。

- 点击「打开三维场景」进入 Viewer；
- 鼠标左键拖动旋转，滚轮缩放，右键/双指拖动平移；
- 底部“重置视角”恢复初始相机，“全屏”切换沉浸模式；
- 「关闭查看器」返回结果；
- 「产物下载」按行显示文件类型、大小和下载入口。需要校验文件时展开「校验值（SHA-256）」；
- PLY 适合后续处理，SPZ 适合在线浏览。指标、报告和产物清单也可单独下载；
- 链接到期后，点击「刷新产物链接」重新获取签名地址。
- “运行日志”显示 Worker 采集的输出，运行中约每 3 秒追加新行；可按级别筛选、“加载更早”。默认每个任务保留最近 2000 行，运维可调整上限。没有日志可能是尚无输出、筛选或保留限制、采集或上报失败等原因，不能仅凭此判断任务状态；上报失败不影响任务执行。

Viewer 加载失败时先检查网络和登录状态，再点击“重新获取场景”。如果任务仍在运行，需等待产物发布完成。

## 7. 分享与下载

- 有写权限的项目成员可在结果页的「管理分享」创建链接。期限可选永久、1 天、7 天或 30 天。链接在创建时完整显示，可复制或使用二维码。
- 持有分享链接的人可直接查看和下载该场景的展示产物。
- 在「管理分享」中撤销后，旧链接立即失效。历史记录可在「已撤销的链接」中展开。
- 分享链接是 bearer URL，不要发布到公开群组或代码仓库。到期后重新创建。

## 8. 桌面端（Windows / Linux / macOS）

Web、桌面、Android 和小程序使用同一服务端账号及项目数据。仓库与 [GitHub Release](https://github.com/FLmhp/ReScene/releases) 已公开，安装包可直接下载；核对 Release 清单中的 SHA-256。当前版本的入口与校验值见 [0.5.1 发布说明](0.5.1发布说明.md)。CI 构建成功不等于每个平台均已完成安装实测。

### Windows

安装文件：发布目录中的 `ReScene_<版本>_x64-setup.exe`。

1. 运行安装程序。未配置商业代码签名证书时 Windows SmartScreen 会提示“未知发布者”；核对发布清单中的 SHA-256 后再选择“仍要运行”。
2. 安装完成后从开始菜单启动 ReScene。桌面端连接 <https://api.rescene.xyz> 和 <https://app.rescene.xyz>。
3. 使用同一团队邮箱登录。桌面端与 Web 共用项目、任务和分享数据。
4. 从已完成任务的「结果」打开 Viewer。首次加载时应用核对产物大小及 SHA-256 并写入本地缓存，再次打开时优先读取校验通过的缓存。
5. 更新：退出应用后运行同一发布者的新版本安装包覆盖安装。当前版本不提供自动更新服务。
6. 卸载：Windows“设置 → 应用 → 已安装的应用 → ReScene → 卸载”。卸载程序会移除安装目录和卸载注册项；浏览器/服务端数据不受影响。

0.4.1 候选包已在 Windows 验证覆盖安装、结果布局、SPZ 渲染、五种产物下载和分享撤销。Linux/macOS 安装实测仍待完成。 [Windows 结果页截图](https://github.com/FLmhp/ReScene/blob/f999157c9ff04df1f33e820f7bd6742444ae6e92/artifacts/test-runs/2026-11-20-release-041/screenshots/windows-native-result-layout.png)

### Linux

安装文件：发布目录中的 `ReScene_<版本>_amd64.deb` 或 `ReScene_<版本>_amd64.AppImage`。两者都未签名，先核对发布清单中的 SHA-256。

1. deb：`sudo apt install ./ReScene_<版本>_amd64.deb`；卸载时使用安装包声明的包名。
2. AppImage：`chmod +x ReScene_<版本>_amd64.AppImage` 后直接运行，不需要安装。
3. 运行需要系统提供 WebKitGTK 4.1 与 AppIndicator 运行库；缺失时用包管理器安装 `libwebkit2gtk-4.1-0` 与 `libayatana-appindicator3-1`。

### macOS

安装文件：发布目录中的 `ReScene_<版本>_universal.dmg`（Intel 与 Apple Silicon 通用），未签名也未公证。

1. 打开 dmg，把 ReScene 拖入“应用程序”。
2. 首次打开被 Gatekeeper 拦截时，右键 ReScene →“打开”，或执行 `xattr -d com.apple.quarantine /Applications/ReScene.app`。
3. 不要把“已下载成功”当作“已通过 Apple 公证”：本版本没有 Apple 开发者证书。

## 9. Android 与微信小程序

### Android

0.4.0 Release 提供 `ReScene_0.4.0_android.apk`，版本码为 5。此前 0.4.1 候选签名 APK 的版本码为 6，真机验证过覆盖安装、图片与视频上传及图片重建后的下载与分享。该结果不替代审计集成版的真机复测。0.5.0 的 Android 包尚待构建、验签和覆盖安装核验，计划版本码为 7。

1. 在 Android 设置中允许当前文件管理器/浏览器“安装未知应用”。
2. 安装 APK 并用团队邮箱登录；凭据保存在 Android Keystore 支持的 SecureStore 中。
3. 项目页可创建项目、上传图片/视频、查看任务、取消/重试和打开 Viewer。
4. Android 上传使用 PostObject 表单直传 OSS，仍受服务端单文件 5 GiB、任务 8 GiB 约束。
5. 退出登录会先请求服务端撤销会话，再清理本地凭据；网络失败时也会尽力清理本地凭据并提示。
6. 更新需安装同一签名的新 APK；签名不一致时 Android 会拒绝覆盖安装。

Viewer 通过原生获取短期签名地址后加载，Bearer token 保存在原生端。

### 微信小程序

小程序使用 Taro 构建，支持邮箱密码登录、OSS 直传和任务轮询。密码至少 12 位，首次使用可在登录页切换到「注册」。正式发布需要以下配置。

- 小程序 AppID `wxedb245fb415d436e` 的开发与发布权限；
- 按微信要求配置的请求、上传和下载域名；
- 隐私指引、类目和发布审核。

微信公众平台“开发管理 → 开发设置 → 服务器域名”应配置：

| 类型 | 域名 |
|---|---|
| request 合法域名 | `https://api.rescene.xyz` |
| uploadFile 合法域名 | `https://rescene-prod-741277.oss-cn-beijing.aliyuncs.com` |
| downloadFile 合法域名 | `https://api.rescene.xyz`、`https://rescene-prod-741277.oss-cn-beijing.aliyuncs.com` |
| socket 合法域名 | 留空，当前未使用 WebSocket |

从「素材」选图后点「选择路线」。提交后自动进入「任务与结果」，可查看进度和分享。当前 AppID 使用个人主体，三维 Viewer 在手机浏览器中打开。项目成员可点「复制浏览器查看链接」，粘贴到手机浏览器并登录查看。接收者可复制公开分享链接，在手机浏览器直接查看。微信转发页也提供复制入口。 [Taro WebView 文档](https://docs.taro.zone/docs/components/open/web-view)

真实 AppID 已验证登录、图片上传、排队和手机浏览器打开分享链接。用户已确认 `1c5e658` 微信体验版冷启动能直接进入登录页或项目列表。新版主题选择和分区导航仍待完整复测。小程序每次最多选择 8 个文件，单文件最多 10 MiB，可分批上传后组合选取同一场景素材。

## 10. 数据与隐私

- 上传原图/视频和重建产物存放在私有 OSS 桶，通过短期签名 URL 访问。
- 服务端保存账号、项目、成员、任务、阶段和审计记录；密码只保存哈希。
- 分享页按 token 公开访问，撤销后失效；不要把含 token 的链接提交到公开仓库。
- 备份与保留策略由运维配置；需要删除账号或项目数据时联系管理员。
- 不要上传无权处理的他人影像、机密图纸或含个人敏感信息的素材。

## 11. 常见问题

**登录后一直显示“正在恢复会话”**  
检查网络和 API 健康页 <https://api.rescene.xyz/health/ready>；若会话过期，重新登录。

**上传到 99% 后失败**  
通常是 OSS 校验或网络中断。先点击“重试上传”；多次失败时换网络并确认文件未超过 5 GiB、任务合计未超过 8 GiB。

**任务一直 QUEUED**  
Worker 离线或正在执行其他任务。左侧 Worker 状态为“离线”时等待运维恢复；不要重复创建相同任务。

**任务成功但 Viewer 空白**  
先点“刷新产物链接”或“重新获取场景”；仍失败时记录任务 ID、时间和端（Web/Windows/Android），提交给运维。

**分享链接打不开**  
确认未到期、未被撤销，且复制的是完整链接；重新创建分享并立即复制。

**Windows 提示未知发布者**  
当前安装包未使用商业代码签名证书。用发布清单核对 SHA-256 后再运行；不要关闭 SmartScreen 全局保护。

**Android 无法覆盖安装**  
新旧 APK 必须使用同一 release keystore。签名不一致时先卸载旧版再安装，卸载会清除本地登录状态。
