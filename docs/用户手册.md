# ReScene 用户手册

> 版本：0.2.1（2026-11-10）  
> 在线工作台：<https://app.rescene.xyz>  
> 本文只描述 0.2.1 已实现并验收的行为。企业微信/小程序正式发布仍受外部主体资质限制，见第 9 节。

## 1. 快速开始

1. 打开 <https://app.rescene.xyz>，输入管理员创建的团队邮箱和密码。
2. 在左侧“项目”栏创建项目，或选择已有项目。
3. 上传一组围绕目标拍摄的图片，或上传一段连续视频。
4. 选择 FAST、BALANCED 或 QUALITY，点击“开始重建”。
5. 等待 GPU Worker 执行。任务成功后打开场景，检查渲染、下载 PLY/SPZ，或创建分享链接。

账号不开放自助注册。忘记密码、需要新成员或调整权限时联系项目 owner 或管理员。

## 2. 账号、项目与权限

| 角色 | 查看素材/任务/结果 | 上传、建任务、取消任务 | 项目设置、成员、删除、分享管理 |
|---|---:|---:|---:|
| `owner` | 是 | 是 | 是 |
| `admin`（平台管理员） | 是 | 是 | 是 |
| `member` | 是 | 是 | 否 |
| `viewer` | 是 | 否 | 否 |

- 左侧栏显示当前邮箱和角色；Worker 在线状态为实时提示，离线时任务保持排队，Worker 上线后继续。
- 窗口宽度小于 1024px（手机、平板竖屏）时侧栏折叠为抽屉：点左上角 `☰` 打开，点项目或按 `Esc` 关闭；页面不再横向滚动。
- “通知”面板可按“未读/全部”筛选、加载更多；公告会带“公告”标签，任务通知点开即跳到对应任务。
- 项目 owner/管理员可在“项目设置”重命名项目、添加或移除成员、删除项目。
- 删除项目会隐藏项目及其任务；已创建的公开分享链接应在“管理分享”中撤销。
- 页面断网时顶部会提示；恢复网络后可继续上传、查询任务和查看结果。

### 管理控制台（仅平台管理员）

平台管理员在左侧栏有“管理控制台”入口，Web、桌面端、Android 与小程序提供同一套三个页签：

| 页签 | 能做什么 |
|---|---|
| 用户 | 按邮箱搜索、按启用状态筛选、分页浏览；停用/启用账号、重置初始密码、查看账号加入的项目与角色、创建账号 |
| 公告 | 发布标题 + 正文 + 级别（信息/警告/重要）；撤回公告 |
| 操作日志 | 按操作者邮箱、动作、项目 ID、起止时间筛选并分页；导出 CSV |

- 停用账号或重置密码会立刻让该账号的所有会话失效，对方下次请求返回 401。
- 初始密码至少 12 位；重置后需把新密码线下告知对方。
- 公告发布时会给每个“启用”状态的账号各写一条通知；撤回公告会同时删除这些通知。
- 操作日志的“动作”支持选择已有动作，也可以输入前缀（如 `user.`）匹配一组动作；CSV 为 UTF-8 BOM，最多导出 10000 行。
- 普通账号看不到入口，直接调用对应接口返回 403。

## 3. 拍摄与素材准备

- 围绕目标平稳移动，保持相邻照片有较大重叠；避免只在一个方向拍摄。
- 避免运动中的行人、车辆和反光/透明表面占据主体；固定曝光和白平衡可减少颜色跳变。
- 图片支持 JPG/PNG 等常见格式；视频支持 MP4/MOV/MKV/AVI/WEBM/M4V。
- 一个任务选择同一组图片，或且仅一个视频，不能混选。
- 建议 20–80 张图片用于常规场景；QUALITY 可处理更多帧，但耗时和显存更高。
- 上传上限：单文件 5 GiB，任务合计 8 GiB。浏览器分片上传写 OSS，刷新页面后可从本地断点继续。

## 4. 上传、排队与取消

1. 打开项目，在“素材”区域选择图片或视频。图片可多选，视频只选一个。
2. 每个文件显示上传进度和状态：
   - `UPLOADING`：正在上传；
   - `READY`：服务端已通过 HEAD 与 SHA-256 校验；
   - `FAIL`：上传或校验失败，可点击“重试上传”。
3. 只有 `READY` 素材可参与任务。选择至少 8 张图片或一个视频后，“开始重建”才可用。
4. 选择路线后点击“开始重建”。任务进入 `QUEUED`，Worker 领取后变为 `RUNNING`。
5. 任务运行中可点击“取消任务”。取消会请求 Worker 停止；状态以服务端返回为准。
6. 失败或取消的任务可点击“重试任务”。重试会复用同一组素材并创建新的执行。

断点上传的本地记录保存在浏览器/客户端本地存储。清除站点数据或换设备后，需要重新上传。

## 5. 路线选择

| 路线 | 适合场景 | 特点 |
|---|---|---|
| FAST | 构图检查、快速预览 | VGGT 前馈几何，7k 步训练，最快 |
| BALANCED | 默认交付、画质与耗时平衡 | VGGT + Bundle Adjustment，20k 步 |
| QUALITY | 高精度几何与最终展示 | COLMAP SfM/BA/MVS，20k 步；耗时最长，注册率可能低于 100% |

路线是质量/资源取舍，不是“同一结果的不同速度”。需要可复现的比较请使用同一素材、同一路线和同一验证集。

## 6. 任务详情与 Viewer

任务详情显示状态、路线、阶段记录、耗时、指标和产物。任务成功后：

- 点击“打开三维场景”进入 Viewer；
- 鼠标左键拖动旋转，滚轮缩放，右键/双指拖动平移；
- 底部“重置视角”恢复初始相机，“全屏”切换沉浸模式；
- “关闭查看器”返回任务；
- 可下载 PLY/SPZ。PLY 适合后续处理，SPZ 体积更小、适合在线浏览；
- “刷新产物链接”会重新获取短期签名地址，旧地址过期后使用此操作。
- “运行日志”显示 Worker 的原始输出，运行中每 3 秒追加新行；可切换全部/信息/警告/错误级别，“加载更早”回看历史，每个任务保留最近 2000 行。日志缺失说明 Worker 上报失败，不影响任务本身。

Viewer 加载失败时先检查网络和登录状态，再点击“重新获取场景”。如果任务仍在运行，需等待产物发布完成。

## 7. 分享与下载

- 在任务详情点击“创建分享”，可设置到期时间；分享链接只在创建时完整显示，请立即复制。
- “复制分享链接”生成公开分享页，任何持有链接的人可查看和下载，不需要登录。
- 分享页只暴露该重建的展示产物，不暴露上传原图或账号信息。
- 在“管理分享”中可撤销链接。撤销后旧链接立即失效；需要重新创建。
- 分享链接是 bearer URL，不要发布到公开群组或代码仓库。到期后重新创建。

## 8. 桌面端（Windows / Linux / macOS）

四端（Web、Windows/Linux/macOS 桌面、Android、小程序）共用同一套项目、任务与分享数据，登录方式一致。

### Windows

安装文件：发布目录中的 `ReScene_<版本>_x64-setup.exe`。

1. 运行安装程序。未配置商业代码签名证书时 Windows SmartScreen 会提示“未知发布者”；核对发布清单中的 SHA-256 后再选择“仍要运行”。
2. 安装完成后从开始菜单启动 ReScene。桌面端连接 <https://api.rescene.xyz> 和 <https://app.rescene.xyz>。
3. 使用同一团队邮箱登录。桌面端与 Web 共用项目、任务和分享数据。
4. 打开已成功的任务可进入 Viewer；SPZ 会缓存在应用缓存目录，二次打开优先使用缓存，失败时回退在线地址。
5. 更新：退出应用后运行同一发布者的新版本安装包覆盖安装。当前版本不提供自动更新服务。
6. 卸载：Windows“设置 → 应用 → 已安装的应用 → ReScene → 卸载”。卸载程序会移除安装目录和卸载注册项；浏览器/服务端数据不受影响。

本机验收记录：0.2.1 覆盖安装、会话保留、Viewer 打开、卸载后安装目录和卸载注册项移除。

### Linux

安装文件：发布目录中的 `ReScene_<版本>_amd64.deb` 或 `ReScene_<版本>_amd64.AppImage`。两者都未签名，先核对发布清单中的 SHA-256。

1. deb：`sudo apt install ./ReScene_<版本>_amd64.deb`；卸载用 `sudo apt remove rescene-desktop`。
2. AppImage：`chmod +x ReScene_<版本>_amd64.AppImage` 后直接运行，不需要安装。
3. 运行需要系统提供 WebKitGTK 4.1 与 AppIndicator 运行库；缺失时用包管理器安装 `libwebkit2gtk-4.1-0` 与 `libayatana-appindicator3-1`。

### macOS

安装文件：发布目录中的 `ReScene_<版本>_universal.dmg`（Intel 与 Apple Silicon 通用），未签名也未公证。

1. 打开 dmg，把 ReScene 拖入“应用程序”。
2. 首次打开被 Gatekeeper 拦截时，右键 ReScene →“打开”，或执行 `xattr -d com.apple.quarantine /Applications/ReScene.app`。
3. 不要把“已下载成功”当作“已通过 Apple 公证”：本版本没有 Apple 开发者证书。

## 9. Android 与微信小程序

### Android

安装文件：发布目录中的 `ReScene_<版本>.apk`，使用固定 release keystore 签名。

1. 在 Android 设置中允许当前文件管理器/浏览器“安装未知应用”。
2. 安装 APK 并用团队邮箱登录；凭据保存在 Android Keystore 支持的 SecureStore 中。
3. 项目页可创建项目、上传图片/视频、查看任务、取消/重试和打开 Viewer。
4. Android 上传使用 PostObject 表单直传 OSS，仍受服务端单文件 5 GiB、任务 8 GiB 约束。
5. 退出登录会先请求服务端撤销会话，再清理本地凭据；网络失败时也会尽力清理本地凭据并提示。
6. 更新需安装同一签名的新 APK；签名不一致时 Android 会拒绝覆盖安装。

本机验收记录：release APK 在 `SLT_API35` 模拟器安装、登录、上传 12 帧、创建任务、任务成功和 Viewer 打开；Viewer 通过原生获取短期签名地址后加载，Bearer token 不进入 WebView。

### 微信小程序

小程序代码位于 `apps/miniapp`，使用 Taro 构建。登录方式与 Web/Android 一致：邮箱 + 密码，密码至少 12 位，首次使用可在登录页切换到“注册”直接创建账号。`Taro.uploadFile` PostObject 上传、任务轮询和 `web-view` 查看均已实现。正式可用还需要外部主体条件：

- 真实小程序 AppID；
- 已备案且加入业务域名的 `app.rescene.xyz`；
- 隐私指引、类目和发布审核。

当前生产环境未配置真实 AppID，因此**不能宣称小程序真机发布已完成**；工程构建和契约测试仍可通过。

## 10. 数据与隐私

- 上传原图/视频和重建产物存放在私有 OSS 桶，通过短期签名 URL 访问。
- 服务端保存账号、项目、成员、任务、阶段和审计记录；密码只保存哈希。
- 分享页按 token 公开访问，撤销后失效；不要把含 token 的链接提交到公开仓库。
- 备份与保留策略由运维配置；需要删除账号或项目数据时联系管理员。
- 不要上传无权处理的他人影像、机密图纸或含个人敏感信息的素材。

## 11. 常见问题

**登录后一直显示“正在恢复会话”**  
检查网络和 API 健康页 <https://api.rescene.xyz/health/ready>；若会话过期，重新登录。

**上传到 99% 后失败**  
通常是 OSS 校验或网络中断。先点击“重试上传”；多次失败时换网络并确认文件未超过 5 GiB、任务合计未超过 8 GiB。

**任务一直 QUEUED**  
Worker 离线或正在执行其他任务。左侧 Worker 状态为“离线”时等待运维恢复；不要重复创建相同任务。

**任务成功但 Viewer 空白**  
先点“刷新产物链接”或“重新获取场景”；仍失败时记录任务 ID、时间和端（Web/Windows/Android），提交给运维。

**分享链接打不开**  
确认未到期、未被撤销，且复制的是完整链接；重新创建分享并立即复制。

**Windows 提示未知发布者**  
当前安装包未使用商业代码签名证书。用发布清单核对 SHA-256 后再运行；不要关闭 SmartScreen 全局保护。

**Android 无法覆盖安装**  
新旧 APK 必须使用同一 release keystore。签名不一致时先卸载旧版再安装，卸载会清除本地登录状态。
