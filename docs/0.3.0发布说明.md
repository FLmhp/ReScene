# ReScene 0.3.0 发布说明

> 发布日期：2026-11-11
> 版本事实源：`VERSION` = `0.3.0`

## 下载

安装包不再放在公网 `/downloads/`，改为 tag 触发 CI 构建并挂到 GitHub Release（仓库私有，仅协作者可见）：

- Release 页面：<https://github.com/FLmhp/ReScene/releases/tag/v0.3.0>
- 清单：[`release-manifest.json`](../artifacts/release/0.3.0/release-manifest.json)（各安装包大小与 SHA-256）、[`source-manifest.json`](../artifacts/release/0.3.0/source-manifest.json)（打包时每个源文件的大小与哈希）

| 文件 | 平台 | 说明 |
|---|---|---|
| `ReScene_0.3.0_x64-setup.exe` | Windows x64 | NSIS，未使用商业代码签名证书 |
| `ReScene_0.3.0_amd64.deb` | Debian/Ubuntu amd64 | 未签名；`sudo apt install ./ReScene_0.3.0_amd64.deb` |
| `ReScene_0.3.0_amd64.AppImage` | Linux amd64 | 未签名；`chmod +x` 后直接运行 |
| `ReScene_0.3.0_universal.dmg` | macOS universal | 未签名、未公证；首次打开需右键“打开”或 `xattr -d com.apple.quarantine` |

Android 本轮未产出：`release.yml` 的 Android job 由仓库变量 `RELEASE_ANDROID_SIGNING` 控制，默认关闭，避免缺少签名 secret 时整条发布链失败。

## 本版内容

- **管理控制台（四端）**：用户目录分页与筛选、账号详情（活跃项目与角色）、公告发布/撤回（发布时向全部活跃账号写通知）、全局操作日志（操作者/动作/项目/时间过滤、动作枚举、CSV 导出最多 1 万行）。
- **任务运行日志**：Worker 按 2 秒增量上报 `worker.log` 与阶段日志，每任务保留最新 2000 行；四端任务面板可查看并按级别过滤，运行态每 3 秒增量轮询。
- **通知中心**：未读计数接口、偏移分页、类型过滤；公告以独立标签进入通知列表，任务通知可直达任务。
- **响应式 Web**：≤1024px 侧栏改为抽屉，≤1100px 主网格单列，≤640px 移动端排版，粗指针设备 44px 触控目标。
- **多平台桌面**：桌面端产物从只有 Windows NSIS 扩展到 Linux deb/AppImage 与 macOS universal dmg；`release.yml` 增加对应 job、发布清单和 GitHub Release 步骤。

## 已知限制

- 三平台桌面产物均未签名（仓库无 Apple/Windows 证书）。macOS 首次打开会被 Gatekeeper 拦截，按用户手册处理，不要把“下载成功”当作“已通过公证”。
- 通知扇出为“发布时写入数据库”，没有邮件或推送；撤回公告会删除对应通知。
- 运行日志是尽力而为的转发：Worker 上报失败不影响任务本身，日志缺失不代表任务失败。
- 分支保护在私有仓库免费套餐下不可用（GitHub 返回 403），改用 CI 的 `commit-messages` 作业校验提交信息。
