# ReScene 0.4.0

Web、Windows、Android 和微信小程序使用统一的素材工作区和主题设置。四端支持跟随系统、浅色与深色，并在当前设备保留偏好。项目和素材缩略图帮助定位场景，路线卡片显示适用情况与帧数，已选数量和 Worker 状态在提交前可见。

| 平台 | 获取方式 | 验收范围 |
|---|---|---|
| Web | [在线工作台](https://app.rescene.xyz) | 生产缩略图加载、历史 SPZ 渲染、宽窄屏双主题 |
| Windows | `ReScene_0.4.0_x64-setup.exe` | x64 覆盖安装、真实账号登录、双主题 |
| Android | `ReScene_0.4.0_android.apk` | 版本码 5，原发布密钥，Android 35 模拟器覆盖安装、登录和重启 |
| 微信小程序 | 微信开发者工具的 0.4.0 开发版或 `ReScene_0.4.0_miniapp.zip` | 真实 AppID、模拟器登录、双主题、素材预览 |
| Linux、macOS | 桌面构建产物见 Release | CI 构建，待安装实测 |

安装包、构建包和 `release-manifest.json` 均在私有仓库的 [GitHub Release](https://github.com/FLmhp/ReScene/releases/tag/v0.4.0) 资产中。0.4.0 发布产物不包含独立的 `SHA256SUMS.txt`：先下载 `release-manifest.json`，再按其中 `artifacts[].size` 和 `artifacts[].sha256` 逐个核对实际下载的文件；`sourceManifest` 记录本次打包的源清单。

Linux / macOS（需安装 `jq`；清单与已下载文件放在同一目录，命令只校验实际存在的文件）：

```bash
jq -r '.artifacts[] | "\(.sha256)  \(.name)"' release-manifest.json \
  | while read -r sha name; do if [ -f "$name" ]; then printf '%s  %s\n' "$sha" "$name"; fi; done \
  | sha256sum -c -
# macOS 把最后的 sha256sum -c - 换成 shasum -a 256 -c -
```

Windows PowerShell：

```powershell
$manifest = Get-Content release-manifest.json -Raw | ConvertFrom-Json
$manifest.artifacts | Where-Object { Test-Path $_.name } | ForEach-Object {
  $file = Get-Item $_.name
  $hash = (Get-FileHash $file -Algorithm SHA256).Hash.ToLower()
  "{0}: size={1} sha256={2}" -f $file.Name, ($file.Length -eq $_.size), ($hash -eq $_.sha256)
}
```

两列结果都应为 `True`。Windows 安装包未使用商业证书，macOS 产物未签名及公证。
