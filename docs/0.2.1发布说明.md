## 本版内容

- Web、Windows、Android 共用冻结的 API/schema/client 契约；Web 与 Windows 工作台完成项目、上传、任务、Viewer、分享闭环。
- Android release 客户端完成邮箱会话、SecureStore、PostObject 上传、任务轮询、系统返回导航、分享和 Viewer。Viewer 通过原生获取短期签名地址，Bearer token 不进入 WebView。
- Viewer 改为按需渲染，移动端像素比限制为 1，降低 Android WebView 卡顿和无响应风险。
- 发布工程增加源清单、发布清单、统一版本校验、Windows NSIS 和 Android 签名构建脚本。
- 公网 `/downloads/0.2.1/` 由 Caddy 只读提供安装包和清单。

## 已知限制

- Windows 安装包未使用商业代码签名证书，SmartScreen 可能显示“未知发布者”。请先核对 `SHA256SUMS`，不要关闭系统安全保护。
- Android APK 使用本地 release keystore 签名；更新必须使用同一签名。未提供 32 位 ABI。
- 微信小程序工程已完成，但生产环境未配置真实 AppID/Secret、业务域名和隐私审核，因此不宣称微信真机发布完成。
- 公网分享链接是 bearer URL，任何持有链接的人可访问；到期或撤销后失效。
- 5090 算法候选和 holdout 结论以独立优化报告为准；未通过的候选不会因为构建发布而自动进入生产默认参数。
