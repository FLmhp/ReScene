# ReScene 0.5.1

[0.5.1 已在私有 GitHub Release 发布](https://github.com/FLmhp/ReScene/releases/tag/v0.5.1)，对应源码提交 `a497b09f05cfd75287defe4398ed456187f03cd8`（合并提交 `73d19fc`）。[主线检查](https://github.com/FLmhp/ReScene/actions/runs/45034474326) 与[标签发行构建](https://github.com/FLmhp/ReScene/actions/runs/45034474406) 全部通过；四个桌面安装包来自同一标签的发行构建，签名 Android APK 从同一提交在本机生成。

## 账号安全

- 登录页新增邮箱验证码登录与忘记密码。验证码 6 位、10 分钟有效、一次性使用、最多 5 次尝试；同一账号 60 秒冷却、每小时最多 5 封，未注册邮箱与已注册邮箱返回相同响应。整条逆链 `401 invalid_code`，尝试次数耗尽返回 `429`，客户端锁定 5 分钟。
- 密码重置撤销全部旧会话与未使用验证码，并直接返回新登录令牌。数据库迁移至 `0011`，只保存验证码的 HMAC-SHA256 摘要；未配置 SMTP 时生产环境返回 202 但拒绝投递，开发环境把验证码写入 API 日志。
- 四端登录页统一为图标与 `ReScene` 居中、标题「验证码登录」；Web、Android、小程序均可从密码登录切换到验证码登录并返回。

## 外观

- 配色预览改为圆角色块加主色调，传统方案更名为青瓷素影、群青远山、墨染松烟、胭脂海棠、朱砂落印、赭石秋峦、靛青夜泊，自定义改为自定主色。未保存过偏好的设备默认跟随系统并使用群青远山。
- Web、桌面、Android 和微信小程序共用同一套设计令牌与配色名称。明暗、配色、字号与面板效果仍按设备保存，退出登录后保留，主题切换不影响上传队列与表单。

## 已知限制

- 当前发布流程没有商业代码签名证书，Windows SmartScreen 会提示未知发布者。macOS 产物未签名、未公证。
- Linux 与 macOS 只记录 CI 构建结果，本机不安装。构建成功不等于平台安装验收完成。
- 本机 Windows 的 Android 原生构建需要把 CMake 暂存目录放到短路径（`scripts/android-windows-cmake.init.gradle`），并给所有原生模块加 220 字符对象路径上限；仓库路径较深时旧脚本无法完成 `expo-modules-core` 与 `react-native-webview` 的编译。该修复不影响已发布的安装包内容。
- 历史验收截图和报告已移出仓库，查看历史链接需要仓库权限。
- 0.5.0 与 0.4.1 的验收不能替代 0.5.1 的构建、真机和生产检查。

## 未覆盖的场景

- 生产 GPU Worker 不在线（`rescene-worker` 未运行），本轮没有提交重建任务，渲染链路沿用在 0.5.0 的验证结果。
- 微信小程序只做了类型检查与构建，没有上传开发版或体验版，没有用真机验证验证码登录。
- Linux `.deb`、Linux `.AppImage`、macOS `.dmg` 与 Windows 安装包本轮均未做本机安装实测。
