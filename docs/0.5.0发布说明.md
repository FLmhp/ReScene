# ReScene 0.5.0

[0.5.0 已在私有 GitHub Release 发布](https://github.com/FLmhp/ReScene/releases/tag/v0.5.0)，对应提交 `3cc98f04cde7c2f6dba056f11ea1a2bd009a75e5`。[主线检查](https://github.com/FLmhp/ReScene/actions/runs/44962626059) 五项通过；四个桌面安装包来自[同一标签的发行构建](https://github.com/FLmhp/ReScene/actions/runs/44963519922)，签名 Android APK 从同一提交在本机生成。

## 界面与客户端

- 官网重做首屏、重建结果、流程、技术路线与交付说明。首屏图片可以点击、触摸或键盘放大查看，动画在减少动态偏好下停用；没有 JavaScript 时正文、菜单和 FAQ 仍可阅读。
- Web、桌面、Android 和微信小程序共用一套设计令牌。配色有青瓷、群青、墨染三套，与浅色/深色偏好分开保存，按设备记住选择。
- 工作台重排登录、侧栏、项目库和素材/任务/结果分区。移动端保留抽屉焦点管理和粘底选材区，分页后不丢已选素材。
- Web、桌面和 Android 在支持背景模糊时使用亚克力控件。微信小程序以同色渐变和半透明底色呈现，旧平台或减少透明度的环境保留清晰的控件底色。

## 已知限制

- 当前发布流程没有商业代码签名证书，Windows SmartScreen 会提示未知发布者。macOS 产物未签名、未公证。
- Linux 与 macOS 只记录 CI 构建结果，本机不安装。构建成功不等于平台安装验收完成。
- Android 正式包必须使用原 release keystore。与旧包签名不一致时只能卸载重装，本地登录状态会清除。
- 微信小程序为个人主体，场景仍在手机浏览器打开。开发版或体验版的上传记录不视为平台正式发布。
- 历史验收截图和报告已移出仓库，链接固定到提交 `f999157c9ff04df1f33e820f7bd6742444ae6e92`，查看需要仓库权限。未提交的本地证据保存在离线归档中。
- 0.4.1 的验收不能替代 0.5.0 的构建、真机和生产检查。

## 未覆盖的场景

本轮部署前检查时生产 GPU Worker 不在线，没有提交训练任务。微信模拟器界面和开发版上传均已核验；没有用体验版扫码验证登录、项目、素材、任务或浏览器分享。
