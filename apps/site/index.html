系统架构与任务调度

客户端通过 API 提交任务和查询进度，PostgreSQL 保存任务状态。GPU Worker 主动领取任务并串行重建，输入与交付文件保存在私有 OSS。

示意：不是实时任务状态

常见问题

素材有什么要求？

选择一组同场景图片或一个视频。图片建议 20–80 张；视角不足可能导致重建失败。

任务为什么会排队？

Worker 可能离线或正在执行其他任务。提交后可在工作台查看队列和任务进度。

如何开始和邀请成员？

使用邮箱注册并创建项目。项目管理者可在成员区签发一次性领取码，转交受邀者以对应邮箱登录领取。

数据边界

输入素材与交付文件保存在私有 OSS。持有有效分享链接的人可以访问对应场景，项目成员可按权限撤销链接。

许可与使用

VGGT-1B 权重受学术非商用许可约束。使用相关路线前请确认适用的许可条件。
