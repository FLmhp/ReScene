系统架构

任务由 API 统一调度，计算与文件存储相互独立。

查看架构说明

客户端经 HTTPS 提交任务并查询进度；PostgreSQL 保存项目、任务与租约状态。GPU Worker 只通过 API 领取租约并上报心跳，不直接连接数据库。素材与交付文件保存在私有 OSS，读取一律使用 API 签发的限时签名地址，分享可按权限撤销。

常见问题

素材有什么要求？

选择一组同一场景的照片或一个视频。图片建议 20–80 张；视角不足可能导致重建失败。

为什么任务会排队？

Worker 可能离线或正在执行其他任务。提交后可在工作台查看队列和任务进度。

如何邀请其他成员？

项目管理者可在成员区签发一次性领取码，受邀者用对应邮箱登录后领取。

如何下载重建结果？

任务完成后打开场景，在交付区域下载 SPZ 或 PLY 文件。

数据与隐私

输入素材与交付文件存储于私有 OSS。分享链接可由项目成员按权限撤销。
