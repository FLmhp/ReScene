系统架构与任务调度

客户端通过 API 提交任务和查询进度，PostgreSQL 保存任务状态。GPU Worker 主动领取任务并串行重建，输入与交付文件保存在私有 OSS。

团队协作与交付

在同一个项目中管理素材、成员和重建结果。

项目权限

用邮箱邀请协作者，为项目成员分配编辑或查看权限。

任务管理

查看阶段和日志，取消任务或重试可恢复的失败。

文件与分享

使用限时链接下载 PLY 或 SPZ，按需创建或撤销场景分享。

常见问题

如何开始？

在工作台使用邮箱注册，密码至少 12 位。登录后即可创建项目并提交素材。

如何添加团队成员？

在项目页「成员」区逐个添加邮箱，选择 member 或 viewer。未注册者使用受邀邮箱注册后自动加入。系统不会发送邀请邮件。

任务为什么会排队？

Worker 可能离线或正在执行其他任务。提交后可在工作台查看队列和任务进度。

许可与数据边界是什么？

VGGT-1B 权重受学术非商用许可约束。持有有效分享链接的人可以访问对应场景，项目成员可以按权限撤销链接。
