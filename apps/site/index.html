02 · 流程

从素材到场景

上传素材后，在工作台跟踪任务状态、阶段日志与结果。

  1. 01 01 UPLOAD

    上传素材

    直传一组同场景图片或单个视频，按项目选择准备好的素材。

  2. 02 02 RECONSTRUCT

    提交 GPU 任务

    选择路线并提交，在队列中查看阶段、日志与可恢复的失败原因。

  3. 03 03 EXPLORE

    浏览与交付

    在 Viewer 检查场景，下载 SPZ / PLY，或创建限时场景分享。

移动端同样跟踪任务

上传、任务与项目导航沿用同一套业务层级，窄屏下以抽屉打开。

03 · 技术

三条重建路线

根据素材规模与交付精度选择配置；步数是场景优化步数，不是重新训练 VGGT。

  • 快速预览

    FAST

    重建管线
    VGGT
    场景优化
    7,000 步
    输入上限
    最多 80 帧
    技术说明

    由 VGGT 估计相机与初始点，不做 Bundle Adjustment。

  • 均衡重建 默认

    BALANCED

    重建管线
    VGGT + BA
    场景优化
    20,000 步
    输入上限
    最多 80 帧
    技术说明

    在 VGGT 结果上执行 Bundle Adjustment，不做稠密重建。

  • 精细重建

    QUALITY

    重建管线
    COLMAP SfM / BA / MVS
    场景优化
    20,000 步
    输入上限
    最多 250 帧
    技术说明

    COLMAP 全流程，包含稠密重建，适合更大规模素材。

系统架构与任务调度

客户端通过 API 提交任务并查询进度，PostgreSQL 保存任务与租约状态。GPU Worker 向 API 领取租约后串行重建；Worker 不直接连接数据库。素材与交付文件保存在私有 OSS。

示意：不是实时任务状态

常见问题

素材、任务与协作的常见处理方式。

素材素材有什么要求？

选择一组同场景图片或一个视频。图片建议 20–80 张；视角不足可能导致重建失败。

任务任务为什么会排队？

Worker 可能离线或正在执行其他任务。提交后可在工作台查看队列和任务进度。

协作如何开始和邀请成员？

使用邮箱注册并创建项目。项目管理者可在成员区签发一次性领取码，转交受邀者以对应邮箱登录领取。

数据边界

输入素材与交付文件保存在私有 OSS。持有有效分享链接的人可以访问对应场景，项目成员可按权限撤销链接。
