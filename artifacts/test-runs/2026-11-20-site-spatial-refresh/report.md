# ReScene 官网改版验收

2026-11-20，使用 Node.js 22、pnpm 10.18.3 和 Microsoft Edge 在本地测试官网生产构建。此目录的截图来自该构建。

| 检查 | 结果 |
| --- | --- |
| 类型检查、Vite 生产构建 | 通过 |
| 360、390、768、1440 像素视口 | 布局与交付表格无横向溢出，手机和桌面首屏顺序正确 |
| 键盘与导航 | 跳到正文、手机菜单打开和焦点返回、成果与交付锚点、架构与 FAQ 折叠均通过 |
| 减少动态效果 | 首屏线框停止播放入场动画，锚点使用即时滚动 |
| 禁用 JavaScript | 在 390 像素视口中可打开导航、跳到重建成果、加载截图和展开折叠内容 |
| 版本与入口 | 四端验证状态、0.4.0 正式版、0.4.1 候选版和工作台链接可见 |
